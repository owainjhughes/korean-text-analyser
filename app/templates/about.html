About

How Saebae classifies Korean word difficulty.

How to use

  1. Navigate to the Home page.
  2. Enter Korean text in the text area.
  3. Click Analyse to classify each word by difficulty level.

How it works

Text is tokenised using the Okt morphological analyser from KoNLPy. Each token is then looked up against the Korean Basic Dictionary API (KRDict), which returns a grade indicating whether the word is elementary, middle school, or high school level.
