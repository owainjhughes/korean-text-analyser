About Saebae

Korean vocabulary difficulty classifier.

What it does

Saebae takes Korean text, tokenises it using KoNLPy (Okt analyser), and looks up each word in the KRDict open dictionary API to retrieve its TOPIK difficulty grade.

Difficulty grades

  • 초급 Elementary — TOPIK I vocabulary
  • 중급 Intermediate — TOPIK II mid-level vocabulary
  • 고급 Advanced — TOPIK II upper-level vocabulary
  • Unknown Not found in KRDict or no grade assigned

Tech stack

  • FastAPI + Jinja2 templates
  • KoNLPy (Okt) for Korean morphological analysis
  • KRDict API for word grade lookup
  • Tailwind CSS (CDN)
