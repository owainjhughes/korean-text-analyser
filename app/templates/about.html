How to use

1. Navigate to the Classifier page.
2. Enter Korean text in the provided text area.
3. Click the "Analyze" button to classify the words in the text.

How does it work?

The application uses the Okt tokenizer from the KoNLPy library to tokenize Korean text. It then classifies each word based on its grade level using the KRDict OpenAPI. The results are displayed in a table showing words classified into elementary, middle school, high school, and other categories.
